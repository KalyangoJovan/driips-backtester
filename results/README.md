# Results

Artifacts generated by a REAL-mode run of
[`notebooks/backtest.ipynb`](../notebooks/backtest.ipynb) on local
Nasdaq-100 E-mini 1-minute exports (the exports themselves are never
committed — see [`data/README.md`](../data/README.md)).

## Labels for every artifact below

- **Data period:** 2025-07-04 → 2026-08-11 (285 usable cash sessions).
- **Mode:** REAL (vendor 1-minute exports).
- **Split:** held-out out-of-sample year 2025-07-01 → 2026-07-01
  (exclusive); the development (in-sample) period predates the shipped
  exports and is not recomputable here; the remainder
  (2026-07-01 → 2026-08-11) is a post-OOS forward sample.
- **Costs:** 0.225 pts commission + 0.5 pts slippage per round turn,
  deducted in R. Gross figures are before costs, net after.

The same label is stamped on the footer of each image.
